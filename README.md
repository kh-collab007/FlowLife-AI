# FlowLife AI
## AIと、より良い毎日へ。
FlowLife AIは、日々の生活の中で「何から始めるべきか」を考える時間を減らし、AIがユーザーの予定や行動に優先順位を付け、その日にやるべきことを提案する生活支援サービスです。
## Vision
人は毎日、「何から始めるべきか」という小さな意思決定を何度も繰り返して生活しています。
FlowLife AIは、その迷う時間を減らし、一人ひとりがより充実した毎日を送れることを目指して開発しています。
